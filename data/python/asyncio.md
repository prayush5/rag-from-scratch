# Python asyncio Basics

`asyncio` is a standard library used to write concurrent code using the `async`/`await` syntax.

## Core Concepts

- **Event Loop**: The core engine that manages and executes asynchronous tasks.
- **Coroutines**: Functions defined with `async def` that can pause execution using `await`.
- **`asyncio.gather`**: Concurrently runs multiple asynchronous operations and waits for all of them to complete.
