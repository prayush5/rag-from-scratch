A Python generator is a specialized class of functions designed to simplify the implementation of custom iterators by leveraging lazy evaluation rather than eager computation. Unlike standard Python functions that execute to completion, construct an entire collection in memory, and deliver it via a single `return` statement, a generator function utilizes the `yield` keyword to emit values sequentially on demand. When a generator function is invoked, Python does not execute its body immediately; instead, it returns a generator object that natively adheres to the iterator protocol by automatically implementing the `__iter__()` and `__next__()` methods. Each time `next()` is called on the generator object, execution proceeds until it encounters a `yield` statement. At this point, the generator yields the computed value back to the caller and pauses its execution state. Crucially, the interpreter preserves the entire execution context—including local variable bindings, code flags, and the instruction pointer—within its stack frame. When `next()` is called again, execution resumes immediately after the last executed `yield` expression rather than restarting from the top. Once the generator function finishes executing or hits an explicit `return`, it raises a `StopIteration` exception, cleanly notifying caller constructs like `for` loops that the data sequence has ended.

From an architectural standpoint, the primary value of generators lies in their ability to achieve $O(1)$ auxiliary space complexity regardless of dataset scale. When processing massive log files, database streams, or mathematical infinite series, constructing a standard list requires loading every item into RAM simultaneously, leading to severe memory bloat or system memory exhaustion. Generators bypass this limitation by generating single data elements just in time, allowing programs to process gigabytes or terabytes of data with a near-zero memory footprint. Beyond generator functions, Python offers generator expressions—a lightweight, syntactically concise alternative similar to list comprehensions but wrapped in parentheses `(expression for item in iterable)`. Furthermore, generators support advanced bidirectional data pipelines through specialized methods: `.send(value)` allows callers to pass values back into the paused generator frame, `.throw(typ)` raises exceptions directly inside the generator execution context, and `.close()` terminates the generator prematurely to trigger cleanup. These features make generators fundamental to building memory-efficient data processing pipelines and cooperative multitasking coroutines in Python.
